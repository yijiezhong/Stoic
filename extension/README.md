# 知止 Stoic 浏览器扩展（骨架）

状态：**骨架**。与主应用尚未联动，站点列表需在扩展弹窗内手动配置。

## 它能做什么

- 在 Chrome / Edge（Manifest V3）里拦截你填写的域名。
- 保存后立即生效，不需要重启浏览器。

## 它不能做什么

- 不会监听知止的计时状态（需要原生消息通道，属 v1.1）。
- 不对 Safari 生效（需要单独的 Safari 扩展工程与签名）。

## 安装（开发版）

1. 打开 `chrome://extensions`，开启「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录。
3. 点扩展图标，每行填一个域名，保存。

## 与主应用的关系

当前互不影响：
- 主应用的应用屏蔽只做「提醒」，不拦截浏览器。
- 扩展独立拦截站点，不知道计时是否在跑。

v1.1 计划：主应用通过本地 HTTP 或原生消息把「专注中」状态与站点列表推给扩展。
