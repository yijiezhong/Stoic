知止 Stoic

会复盘的番茄钟。25 分钟专注，结束后看见你什么时候最容易进入状态。

下载 macOS 版

macOS 14 及以上 · 约 1 MB · 中英双语

它做什么

  • 菜单栏计时：开始 / 暂停 / 跳过，不打断当前窗口
  • 任务清单：截止日、提醒、重要紧急、预计番茄数
  • 记录与复盘：每天统计、连续天数、周复盘与高峰时段
  • 专注块：25 / 50 / 90 分钟三种模式
  • 本地优先：数据只在你电脑上，可导出 JSON / CSV
