# 知止 Stoic 隐私政策

生效日期：2026-11-16

适用版本：知止 Stoic 0.1.x（macOS）

## 一句话

你的任务、备注与番茄记录只存在你自己的电脑上；应用默认不联网，唯一的网络行为都由你主动触发。

## 一、我们收集什么

**默认：什么都不收集。**

应用首次启动时不含任何账号体系，不需要登录，也没有设备标识符上报。

## 二、数据存在哪里

| 数据 | 位置 |
|---|---|
| 任务、记录、设置 | `~/Library/Application Support/default.store`（SwiftData） |
| 运行中的计时状态 | `UserDefaults`（`stoic.timer.snapshot`） |
| 匿名统计（若开启） | `UserDefaults`（`stoic.telemetry.summary`） |

卸载应用后，上述文件不会被自动删除；你可以手动删除该目录以彻底清除。

## 三、哪些操作会联网

| 操作 | 触发方式 | 发送内容 |
|---|---|---|
| 检查更新 | 你点「检查更新」 | 一个 GET 请求，取版本 JSON |
| 提醒事项同步 | 你点「立即同步」并授权 | 读写你本机的提醒事项（不经过网络） |
| 打开赞助页 | 你点「打开赞助页」 | 用浏览器打开你填写的链接 |
| 匿名统计上报 | 你开启开关并调用 flush | 仅计数，见第四节 |

## 四、匿名统计（默认关闭）

开启后只累计以下计数：

- 启动次数
- 完成的番茄数
- 跳过的段数

**不包含**：任务名、备注、日期时间、设备信息、IP、账号。

关闭开关会清空本地计数。

## 五、数据导出与删除

- 设置 →「数据」→ 导出 JSON / CSV，可完整带走。
- 删除应用数据：退出应用后删除 `~/Library/Application Support/default.store`。

## 六、第三方

本应用不集成广告 SDK、不集成分析 SDK、不使用账号登录。

## 七、联系方式

隐私问题请通过你在「关于」中填写的赞助/联系页面联系作者。

## 八、变更

政策更新会随版本发布，并在本文件保留日期。
